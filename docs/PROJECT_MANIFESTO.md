# PROJECT MANIFESTO

## Why This Project Exists

Many NGOs struggle to convince donors that donations reach the intended beneficiaries.

Traditional donation systems often rely on trust alone.

Donors usually receive limited information after making a donation and have little visibility into how their contribution is handled.

This project aims to improve transparency by combining a modern donation management platform with blockchain technology.

The goal is not to replace existing financial systems but to strengthen trust through immutable donation records.

---

## Vision

To become a modern, secure and transparent donation platform where every donation can be verified without requiring users to understand blockchain technology.

Blockchain should work silently in the background while users enjoy a simple and familiar donation experience.

---

## Mission

Develop an application that enables NGOs to manage fundraising campaigns while giving donors confidence that every completed donation has a permanent and verifiable proof.

---

## Product Philosophy

This project should feel like commercial software rather than a university assignment.

Every page should be clean.

Every interaction should feel intentional.

Every component should be reusable.

Every animation should have a purpose.

---

## User Experience Philosophy

Technology should never overwhelm users.

Donors should not need cryptocurrency knowledge.

Payments should feel familiar.

Navigation should be simple.

Information should be easy to understand.

---

## Development Philosophy

Quality over quantity.

Consistency over complexity.

Maintainability over shortcuts.

Documentation before implementation.

Reusable code before duplicated code.

---

## Long-Term Goal

Although this project is developed as a Final Year Project, the architecture should be scalable enough to evolve into a real NGO donation platform capable of serving organizations across Tanzania.
