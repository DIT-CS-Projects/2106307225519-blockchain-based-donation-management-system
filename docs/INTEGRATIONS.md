# External Integrations

This document describes every third-party system connected to the application.

---

# Payment Gateway

Gateway

AzamPay (Decision 009)

Purpose

Process donations using Tanzanian payment methods.

Supported

* M-Pesa
* Airtel Money
* Mixx (formerly Tigo Pesa)
* HaloPesa
* Tanzanian Banks

Future support

* Visa
* Mastercard

# Integration Principles

Every external integration should:

* Be securely authenticated.
* Use encrypted communication.
* Be independently replaceable.
* Fail gracefully without affecting the entire system.
